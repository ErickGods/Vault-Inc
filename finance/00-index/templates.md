# Índice — Templates

Estruturas prontas para os entregáveis recorrentes da casa. Não são conhecimento: são o
formato que o conhecimento assume quando vira entrega.

**O preenchimento sai daqui, o entregável vai para o repositório privado.** O template mora
neste vault porque a estrutura é durável e revisável; a instância preenchida carrega dado de
cliente ou posição e não pode voltar para cá.

Os campos entre chaves duplas — `{{ticker}}`, `{{date}}` — são placeholders. O verificador de
links os ignora por forma, em qualquer pasta, então não os transforme em wikilink.

| Template | Quando usar | Nível |
|---|---|---|
| [[stock-analysis-template]] | Iniciar cobertura de uma ação: visão geral, tese, setor, 5 anos de demonstrações, valuation, riscos e recomendação. É o esqueleto que a skill `equity-initiation` preenche. | intermediate |
| [[earnings-call-notes]] | Registrar uma teleconferência de resultado: números-chave, breakdown por segmento, margens, guidance e as citações que revelam mudança de tom da gestão. | intermediate |
| [[portfolio-review-template]] | Revisão periódica de carteira: alocação atual contra alvo, performance contra benchmark, necessidade de rebalanceamento e avaliação de risco. | intermediate |
| [[trade-journal-template]] | Documentar uma operação antes e depois: setup, tese, dimensionamento, checklist de entrada e revisão pós-trade. Existe para separar decisão boa de resultado bom. | intro |
| [[monthly-finance-review]] | Revisão financeira pessoal mensal: renda, despesas em 50/30/20, taxa de poupança, aportes e evolução do patrimônio. | intro |
